### Projets Mis en Avant

Voici une sélection de mes projets, allant du scripting d'administration aux applications embarquées :

**1. Data Job Tracker : Pipeline ETL & IA Générative Local**
Un pipeline de données conteneurisé "End-to-End" pour automatiser l'analyse du marché de l'emploi Data.
* **Technologies :** Python, Docker, PostgreSQL, LLM (Meta Llama 3.2), Metabase.
* **Réalisations :** Architecture micro-services sous Docker. Scraping automatisé multi-sources d'offres d'emploi. Utilisation d'une IA locale (sans coût d'API) pour extraire intelligemment les compétences requises et générer des résumés en JSON. Stockage des données propres dans PostgreSQL et visualisation via un Dashboard Metabase.

**2. Système de Monitoring de Parc Informatique**
Une solution d'administration complète pour surveiller des serveurs Linux à distance, conçue pour tourner en autonomie.
* Technologies : Python, Bash, Flask, SQLite.
* Réalisations : Déploiement de sondes via SSH, automatisation de la collecte des métriques (CPU, RAM, Disque), système d'alerte par email, et tableau de bord web générant des graphiques d'évolution. Intégration d'une veille de cybersécurité automatisée (scraping du CERT-FR).

**3. Système de Comptage de Personnes (IoT)**
Un projet faisant le pont entre le matériel électronique et une architecture logicielle sécurisée.
* Technologies : C++, Arduino, TLS/SSL, Python.
* Réalisations : Programmation des capteurs de passage sur Arduino, développement d'un serveur de réception C++ hautement sécurisé écoutant en continu, et interface de visualisation en temps réel.

**4. Jeu d'Arcade Rétro (Shoot 'em up)**
Un projet axé sur la logique algorithmique et la gestion de données locales.
* Technologies : Python (moteur Pyxel), SQLite.
* Réalisations : Développement complet de la boucle de jeu, gestion des collisions et de la difficulté, avec un système de persistance des statistiques et des scores via une base de données embarquée.
